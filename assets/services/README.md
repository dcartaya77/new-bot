# 📸 Banco de Imágenes de Servicios

Coloca en esta carpeta las fotografías reales de tus trabajos para que el bot y la IA puedan mostrarlas a las clientas cuando pregunten por los resultados de cada servicio.

### Nombres de archivo admitidos (formatos: .jpg, .jpeg, .png, .webp):

1. **Diseño y Depilación con Henna:**
   - `cejas_henna.jpg` (o `cejas_henna.png`)

2. **Extensiones de Pestañas Pelo a Pelo:**
   - `extensiones_pestanas.jpg` (o `extensiones_pestanas.png`)

3. **Lash Lifting y Tinte de Pestañas:**
   - `lash_lifting.jpg` (o `lash_lifting.png`)

4. **Micropigmentación / Microblading:**
   - `microblading.jpg` (o `microblading.png`)

> [!TIP]
> Si una imagen no existe en la carpeta, la IA responderá la explicación en texto normalmente sin generar error.
